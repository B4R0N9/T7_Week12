# Dashboard Analisis Penjualan Supermarket

## Deskripsi Program

Program ini merupakan aplikasi desktop berbasis Python menggunakan framework PySide6 yang digunakan untuk melakukan analisis data penjualan supermarket. Program ini menampilkan data penjualan dalam bentuk tabel dan visualisasi grafik sehingga mempermudah pengguna dalam memahami informasi penjualan.

Aplikasi ini menggunakan dataset `supermarket_sales.csv` dan menampilkan beberapa fitur seperti:

- Menampilkan data penjualan supermarket
- Filter data berdasarkan branch
- Pencarian data secara realtime
- Visualisasi grafik batang
- Visualisasi grafik pie
- Menampilkan statistik total sales
- Menampilkan jumlah transaksi
- Export grafik ke file PNG

---

## Tools dan Library

Program ini dibuat menggunakan:

- Python
- PySide6
- Pandas
- Matplotlib
